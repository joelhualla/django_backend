## Configuración de Base de Datos (Scripts SQL)
El proyecto incluye el script de inicialización en `database/init.sql`, el cual:
1. Crea la base de datos `db_recetas`.
2. Crea el usuario `admin_recetas`.
3. Asigna privilegios totales sobre la base de datos.
